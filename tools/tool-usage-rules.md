# ツールの使い方

この規則は、Slack ブリッジ経由で動かす agy プロジェクトに共通です。実体はブリッジのインストール先の
`tools/tool-usage-rules.md` で、各プロジェクトの `.agents/rules/tool-usage-rules.md` はそこへの
シンボリックリンクです（`setup_agy_project.py` が張ります）。安全規則（`agent-safety-rules.md`）とは別の、
作業を無駄なく進めるための規則です。

1. **組み込みのツールで処理できることには、コマンドやスクリプトを使いません。** まず組み込みのツール
   （`read_file` など）を試してください。コマンドを実行したりスクリプトを書いたりするのは、組み込みの
   ツールでは足りなかったときだけです。
2. **組み込みのツールで足りないときは、使いたいコマンドやライブラリが入っているかを、先に調べます。**
   呼んでみて「not found」になるのを繰り返さないでください。調べるときは、候補をまとめて 1 回で調べます
   （例: `which pdftotext tesseract soffice`）。調べるたびに許可の確認が出ることがあるので、回数を減らします。
3. **入っていなかったら、別のものを次々に試しません。** 何が必要で、なぜ必要かをユーザーに報告して、
   指示を待ってください。インストールなどは、ユーザーの指示があってから行います。
